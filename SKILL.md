# PROJECT CONTRACT & SKILLS: CAKE E-COMMERCE PLATFORM

## MANDATORY RULE: EXTEND, DON'T BREAK
1. Never break existing working code, fetchers, routes, context, or database structures.
2. Build real features with functional Firebase integration, not fake UI.
3. Mobile-first design and responsive layout across all device viewports.
4. Keep Firebase reads and operations cost-efficient.
5. Third-party image hosting (Cloudinary) with client-side image compression.
6. Enforce role-based access control (Visitor, Customer, Admin, Super Admin).
7. Handle all UI states: Loading, Empty, Success, Error, and Retry.
